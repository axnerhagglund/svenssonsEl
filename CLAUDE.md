## Architecture

This is a **Next.js 16 App Router** marketing site template for a Swedish trades/craftsman business ("hantverkare"). It is statically generated by default and includes optional Sanity CMS query scaffolding with null-guards so builds work before a CMS project is connected.

### The single source of truth for customisation

**`src/config/client.ts`** — every static customer-facing value (company name, phone, hero copy, stats, meta tags, brand colors) lives here. Components consume `client` or the compatibility `siteConfig` export directly; never hardcode these values in components.

**`src/config/routes.ts`** — all internal paths in one place (`routes.home`, `routes.services`, etc.).

**`src/data/`** — thin Sanity re-export files plus compatibility static data used by the current template pages.

**`src/sanity/`** — Sanity client, queries, document types, and schemas. Query functions return empty data when `NEXT_PUBLIC_SANITY_PROJECT_ID` is not configured.

### Routing

All user-facing pages live under `src/app/`. The root layout wraps pages in `ContactModalProvider → Header → main → Footer → CookieBanner`.

### Contact modal system

A global contact modal is managed via React Context in `src/components/contact/ContactModalProvider.tsx`. Any component that needs to open it calls `useContactModal().open()`. The modal renders `ContactForm` (`src/components/ui/ContactForm.tsx`) and is mounted once at the root layout level. The `/#contact` hash on the home page scrolls to an anchor rather than opening the modal.

### Component layers

- `src/components/layout/` — `Header`, `Footer`, `CookieBanner`
- `src/components/sections/` — full-width homepage sections (`Hero`, `About`, `Services`, `Testimonials`, `ServiceAreas`, `HomeFaq`, `Contact`)
- `src/components/pages/` — content blocks for inner pages (`TjansterHero`, `OmOssHero`, etc.)
- `src/components/ui/` — reusable primitives (`Button`, `FadeIn`, `FaqAccordion`, `FaqPageClient`, `ContactForm`)
- `src/components/contact/` — modal system (`ContactModal`, `ContactModalProvider`, `OpenContactButton`)

### Styling

Tailwind CSS v4 with custom design tokens defined in `src/styles/globals.css` via `@theme`. There is no `tailwind.config.ts`.

- **Colors:** `dark` (#1B2A3B), `accent` (#C9941A), `bg` (#F5F2EC), `muted`, `border`, plus variants `dark-2`, `accent-h`, `accent-dark`, `accent-light`
- **Fonts:** `font-head` (Fraunces serif), `font-body` (Outfit sans-serif) — set as CSS variables in the root layout
- **Max-width:** `max-w-content` = 1200px
- Utility: `cn()` in `src/utils.ts` for conditional class merging

### Environment variables

| Variable | Purpose |
|---|---|
| `NEXT_PUBLIC_SITE_URL` | Canonical production URL for `metadataBase`. Vercel preview builds fall back to `VERCEL_URL` automatically. |
| `NEXT_PUBLIC_SANITY_PROJECT_ID` | Optional Sanity project ID. If unset, CMS queries return empty data. |
| `NEXT_PUBLIC_SANITY_DATASET` | Sanity dataset, default `production`. |
| `NEXT_PUBLIC_SANITY_API_VERSION` | Sanity API version, default `2024-01-01`. |
| `RESEND_API_KEY` | Reserved for contact-form email delivery. |
